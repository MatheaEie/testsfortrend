# testsfortrend
R code for tests for trend in time and event truncated recurrent events data.

The codes for the tests for trend in time truncated data are taken from https://github.com/jtkgithub/trendtests.

The code gendataPLWfeil in Simulation examples.R was given to me by Jan Terje Kvaløy who made it for the simulations done in the article "A Class of Tests for Trend in Time Censored Recurrent Event Data", Technometrics 2020.
